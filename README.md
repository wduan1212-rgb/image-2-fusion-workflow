# AI 提示词工作台

这是一个面向 AI 视频与 Image-2 图片创作的提示词骨架搭建工作台。项目目标不是替用户完整创作内容，而是提供结构化、可选择、可复制的提示词框架，让用户把具体画面、产品、剧情、卖点和口播内容填入其中。

当前版本是可直接部署到 GitHub Pages 的静态网页，入口文件为 `index.html`。

## 核心模块

### 1. 自由搭配视频提示词工作台

视频工作台用于生成结构稳定的 AI 视频提示词。系统提供可选变量与镜头骨架，用户负责填写具体内容。

主要能力：

- 参考图多选开关：支持 `@参考图`、`@参考角色图`、`@参考产品图`、`@参考风格图`。
- 基础参数设置：比例、总时长、输出平台、输出语言、输出模式。
- 风格类型与风格变量树：风格变量可按类型选择，也支持用户新增自定义变量。
- 角色设定变量：角色开关、外貌、穿搭、一致性约束等均为可选。
- 声音变量：BGM、口播、音效等不强制启用。
- 镜头结构：支持 Shot 列表、时间段、用户画面内容、景别、角度、运镜。
- 负面约束：以标签方式多选，可取消。
- 实时预览：根据当前变量与镜头内容生成最终提示词。
- 一键复制：快速复制生成后的提示词。

视频提示词遵循“骨架固定，骨头可选，内脏用户填”的原则：系统只负责搭建提示词结构，不替用户过度扩写剧情或卖点。

### 2. GPT Image-2 快捷提示词模块

Image-2 模块是独立的图片提示词工作区，不与视频工作台混写。

当前模块已接入常用图片提示词库，包含 12 个分类、120 条模板，并使用嵌入式图片预览展示各分类效果。

主要方向：

- 商业海报
- 产品概念图
- 旅行海报
- 教育 / 试卷类
- 包装设计提案
- 安装说明图 / 教程图
- 信息图、展示板与其他图像模板

Image-2 的生成逻辑为：

```text
图片类型 -> 版式 -> 主体/产品 -> 风格 -> 色彩 -> 文案/文字要求 -> 画面细节 -> 负面约束
```

工作区顺序：

```text
分类纵览图片 -> 变量表单 -> 模板卡片 -> 负面约束与自定义变量
```

## 设计原则

- 所有模块都必须可选，不默认假设每条视频都有角色、产品、口播、BGM 或参考图。
- 变量进入最终提示词时保持短文本，不把长篇解释塞进生成结果。
- 详细说明只放在变量详情或帮助说明中。
- 冲突只提醒，不禁止用户继续生成。
- 复杂转场不作为核心模块，默认保持关闭或作为高级可选项。

## 部署结构

- `index.html`：主网页文件，包含页面结构、样式、交互脚本与嵌入式图片资源。
- `.nojekyll`：GitHub Pages 静态站点标记文件，避免 Jekyll 处理静态资源。
- `README.md`：项目说明。
- `AGENTS.md`：项目开发规范与功能原则。

## 使用方式

直接打开 `index.html` 即可运行当前静态网页版本。页面功能集中在浏览器端完成，不依赖后端服务，也不依赖构建工具。
